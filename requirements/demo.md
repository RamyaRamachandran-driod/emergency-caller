# Demo requirements

The user describes a car breakdown and provides its location. The system finds up to three relevant mobile mechanics using location and local time, calls them concurrently, and displays each call status and transcript. It presents availability, arrival estimates, quotes and conditions without inventing unknown values. When a mechanic does not say whether they are available now, availability is shown as unknown rather than as yes or no, and that offer cannot be booked. The user selects an eligible offer and authorizes confirmation. The business must explicitly accept before a booking is shown as confirmed. Duplicate clicks must not dispatch twice. One failed call must not discard other results. Simulation must be visibly labeled and must never dial real numbers. The browser only talks to the app's own server: it never sends requests directly to phone or AI providers such as Twilio, Vonage or OpenAI. The offer details the dashboard shows match the task data the app's server returns for that request.
